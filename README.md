# 📊 Movie Box Office & Financial Performance Dashboard (2024–2026)

**Project Overview**
An interactive Microsoft Excel dashboard designed to analyze global movie box office collections against production budgets to determine year-over-year net profitability trends.

**Key Features**
* **Master Data Management**: Cleaned granular movie data including titles, release years, budgets, collections, and director/production metadata.
* **PivotTable Analytics**: Aggregated total financial metrics with dynamic calculated fields for Net Profit.
* **Interactive Slicer**: Single-click filtering across release years (2024–2026).
* **Visual Trendline**: Incorporated linear regression visuals to track bottom-line trajectory.

**Tools Used**
* **Microsoft Excel**: PivotTables, Calculated Fields, PivotCharts, Slicers, Custom Formatting.
